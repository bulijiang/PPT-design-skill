# PPT-design-skill
是一个帮你逐页生成咨询解决方案类 PPT 详细设计方案的 Claude Skill——它结合品牌配置、项目约束与受控词汇表，把每页大纲细化成包含完整文案、视觉结构和可直接用于 AI 图像生成（image2）的中文视觉提示词的独立文档，并自动管理版本与修订日志。A Claude Code skill that turns a PPT outline into page-by-page design docs: full copy, visual structure, and an image-ready prompt for each slide, with versioning and a revision log.
